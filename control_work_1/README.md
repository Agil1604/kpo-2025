# Отчет по КР1

## Запуск

Работа выполнена на Java с gradle сборкой.

Точкой входа в данное консольное приложение является класс `Application`

## Паттерны

### Паттерн `Фабрика`

Используется как единая точка создания доменных объектов (BankAccount, Category, Operation).

В классе `DomainFactory` предоставлен интерфейс для фабрики создающей все виды доменных объектов,
а в классе `DomainFactoryImpl` предоставлена конкретная реализация 
(это сделано, чтобы не нарушать принципы SOLID, а точнее принцип инверсии зависимостей).

### Паттерн `Фасад`

Используется для объединить по смыслу сервисов и единой точки для управления доменной областью.

Реализация представлена в классе `FinanceFacade`.

### Паттерн `Команда`

Каждая выполняемая приложением команда представлена отдельным классом, с общим методом execute.

При необходимости исполнить команду создается ее экземпляр, который далее выполняется.

### Паттерн `Декоратор`

Используется для подсчета времени исполнения каждой команды (обычная команда оборачивается в `TimedCommand`)

### DI контейнер

Само приложение является DI контейнером (Spring Boot).
